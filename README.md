# simple-chat

Простой real-time чат на Node.js с использованием Socket.IO.

Установка

1. Склонируйте репозиторий:

   git clone <repo-url>
   cd simple-chat

2. Установите зависимости:

   npm install

Запуск локально

- Для продакшн-стартa:

  npm start

  (запускает node server.js — ожидается, что в репозитории есть server.js)

- Для разработки:

  npm run dev

  (установите nodemon глобально или локально, если хотите авто-перезапуск)

Ручная проверка (manual testing)

1. Запустите сервер (npm start).
2. Откройте в браузере http://localhost:3000 или тот порт, который использует сервер.
3. Откройте ещё одно окно/вкладку и подключитесь к тому же приложению.
4. Отправьте сообщение из одного окна, убедитесь, что оно отображается в другом.
5. Проверьте подключение/отключение пользователей, обработку ошибок и логирование в консоли сервера.

Советы по отладки

- Проверьте, что Socket.IO на клиенте использует правильный адрес/порт сервера.
- Включите подробный лог на сервере при необходимости.
- Проверьте CORS-настройки, если клиент и сервер находятся на разных хостах/портах.

Развёртывание

Вариант A — простой (Heroku, Railway и т.п.)

1. Убедитесь, что package.json содержит правильный скрипт start.
2. Запушьте в удалённый репозиторий и задеплойте через провайдера (Heroku, Railway).

Вариант B — VPS / systemd / PM2

1. Установите Node.js на сервер.
2. Скопируйте код на сервер (git clone или rsync).
3. Установите зависимости: npm install
4. Запустите через PM2: pm2 start server.js --name simple-chat
5. Настройте reverse-proxy (nginx) и SSL (Let's Encrypt).

Вариант C — Docker (рекомендуется для консистентности)

1. Создайте Dockerfile с базовым образом node:14/16/18.
2. Соберите образ и запустите контейнер, пробросив порт.

Подготовка коммитов для веток dev/auto

Добавлен вспомогательный скрипт scripts/prepare-commits.js, который создаёт в папке .commits два файла с предложениями сообщений и списком изменений для веток dev и auto.

Использование:

  npm run prepare-commits

Далее можно просмотреть .commits/dev.txt и .commits/auto.txt и применить их при создании коммитов/PR:

  git checkout -b dev
  # внести изменения или добавить уже подготовленные файлы
  git add .
  git commit -F .commits/dev.txt
  git push -u origin dev

  git checkout -b auto
  git add .
  git commit -F .commits/auto.txt
  git push -u origin auto

Примечания

- Убедитесь, что server.js и клиентская часть уже присутствуют в репозитории. Этот шаг не добавляет серверную реализацию, а только инструкции и вспомогательный скрипт для подготовки коммитов.
- Файлы .commits по умолчанию добавлены в .gitignore.
