# chat test 40

Краткое описание

Проект: тестовое чат-приложение версии 40 для проверки функций обмена сообщениями, авторизации и развертывания в среде разработки.

Что сделано в этом шаге

- Добавлен скрипт для подготовки ветки dev/auto (scripts/prepare-dev-auto.js)
- Добавлен минимальный HTTP-сервер в src/index.js
- Обновлён package.json: команды start, test, prepare-dev-auto
- Добавлен .gitignore

Требования

- Node.js >= 16
- Git

Как запустить

1) Установите зависимости:

   npm install

2) Запустить сервер в режиме разработки:

   npm start

   Сервер по умолчанию слушает на порту 3000.

API эндпоинты (минимальная реализация):

- POST /auth/login
  - Тело: { "username": "..." }
  - Возвращает: { "token": "<mock-token>" }

- GET /messages
  - Заголовок: Authorization: Bearer <token>
  - Возвращает список сообщений (in-memory)

- POST /messages
  - Заголовок: Authorization: Bearer <token>
  - Тело: { "text": "..." }
  - Добавляет сообщение в in-memory хранилище

Тесты

- Команда для запуска тестов (jest):

   npm test

Подготовка ветки dev/auto

- Локально можно создать/переключиться на ветку dev/auto и запушить её в origin командой:

   npm run prepare-dev-auto

  Скрипт выполнит попытку переключиться на ветку dev/auto (создаст, если отсутствует) и запушит её:

  - git fetch
  - git checkout dev/auto  (или git checkout -b dev/auto если ветки нет)
  - git push -u origin dev/auto

Примечания

- В этом репозитории уже есть (или ожидается) базовые unit-тесты для авторизации и обмена сообщениями. Если вы добавляете новые тесты, поместите их в каталог __tests__ или в test/ и используйте jest/supertest.
