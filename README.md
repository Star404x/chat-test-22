Проект node-chat

Кратко

Простой веб-чат на Node.js с обменом сообщениями в реальном времени через Socket.IO.

Требования

- Node.js >= 14
- npm

Установка

1. Склонируйте репозиторий и перейдите в папку проекта:

   cd node-chat

2. Установите зависимости:

   npm install

Запуск

- Обычный запуск (по умолчанию ожидается файл server.js):

   npm start

- Если основной файл называется index.js, используйте альтернативный скрипт:

   npm run start:index

- Режим разработки (требует nodemon):

   npm run dev

- Команда, помогающая напомнить про ручное тестирование:

   npm run test:manual

Если сервер использует переменную окружения PORT, можно задать её перед запуском, например:

   PORT=3000 npm start

Ручное тестирование (шаги)

1. Запустите сервер (см. раздел Запуск).
2. Откройте в браузере адрес сервера. Обычно это http://localhost:3000 (или порт, указанный в переменной PORT).
3. Откройте ещё одно окно или вкладку и перейдите по тому же адресу, чтобы имитировать второго пользователя.
4. Введите сообщение в одном окне и отправьте.
5. Подтвердите, что сообщение появляется в другом окне в реальном времени.
6. Проверьте консоль сервера на предмет ошибок и логов подключений/сообщений.
7. В случае проблем откройте инструменты разработчика в браузере (Console/Network) и убедитесь, что сокет подключён и события проходят.

Чек-лист для проверки

- Два клиента видят одинаковые сообщения.
- Подключение и отключение клиентов логируются на сервере.
- Сервер не падает при отправке сообщений.
- Повторное соединение клиента восстанавливает обмен сообщениями.

Отладка и частые проблемы

- Порт уже занят: измените PORT или завершите процесс, занимающий порт.
- nodemon не установлен глобально: используйте npm run dev после npm install, чтобы установить локальную версию.
- Если файлы entry-point называются иначе, обновите поле main в package.json и скрипты в разделе scripts.

Дальше

После ручного тестирования можно добавить автоматические интеграционные тесты, CI-конфиг и инструкции по развёртыванию.
