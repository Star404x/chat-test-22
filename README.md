# chat test 40

Краткое описание

Проект: тестовое чат-приложение (версия 40) для проверки функций обмена сообщениями, авторизации и развёртывания в среде разработки.

Prerequisites

- Node.js 14+ и npm или Yarn
- Git

Установка

1. Клонируйте репозиторий:
   git clone <repo-url>
2. Перейдите в папку проекта и установите зависимости:
   npm install

Запуск

- Запуск в режиме разработки (если в package.json есть скрипт dev):
  npm run dev

- Запуск сервера (production / простая команда):
  npm start

Тесты

- Запустить тесты (Jest):
  npm test

Подготовка ветки dev/auto

В проекте добавлен вспомогательный скрипт для подготовки ветки dev/auto:

- Локально через скрипт:
  ./scripts/prepare-dev-auto.sh

- Или через npm-скрипт (если присутствует в package.json):
  npm run prepare:dev-auto

Скрипт создаёт/пересоздаёт локальную ветку dev/auto, пушит её в origin и устанавливает upstream.

Дополнительно

Если нужно добавить CI/CD или расширить тесты — добавляйте соответствующие workflow или новые тесты в папке tests/.
