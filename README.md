# Простой Node.js бот

Небольшой CLI-чат-бот на Node.js, который отвечает на простые команды и запускается локально.

Текущая реализация:
- Команды: /help, /hello, /exit
- Конфигурируется через переменную окружения BOT_NAME

Требования
- Node.js 14+ (рекомендуется последняя LTS версия)
- npm

Установка
1. Клонируйте репозиторий:

bash
git clone <repo-url>
cd <repo-folder>


2. Установите зависимости (если понадобятся):

bash
npm install


Переменные окружения
- BOT_NAME — имя бота, отображаемое в приглашении и ответах. По умолчанию: "Bot".

Примеры установки переменной окружения и запуска
- macOS / Linux / WSL:

bash
export BOT_NAME="MyBot"
npm start


- Windows (PowerShell):

powershell
$env:BOT_NAME = "MyBot"
npm start


- Запуск без переменных окружения:

bash
npm start


Использование
После запуска бот выведет приглашение вида:

MyBot> 

Доступные команды:
- /help — показать справку
- /hello — бот поздоровается
- /exit — выйти из программы

Пример сессии:


$ BOT_NAME=HelperBot npm start
HelperBot запущен. Наберите /help для списка команд.
HelperBot> /hello
Привет! Я HelperBot. Чем могу помочь?
HelperBot> /help
Доступные команды:
/help - показать справку
/hello - поздороваться
/exit - выйти
HelperBot> /exit
До свидания!
