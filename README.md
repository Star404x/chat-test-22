# mini site boots

Небольшой адаптивный сайт на Bootstrap для демонстрации контента, форм обратной связи и базовой интерактивности.

Технологии
- JavaScript
- Node.js (Express для локального сервера)
- Bootstrap (статические ресурсы в папке public)

Файловая структура (ожидаемая)
- public/        — статические файлы сайта (index.html, css, js, images)
- src/index.js   — простой Express-сервер для локального запуска
- package.json   — метаданные и скрипты

Пререквизиты
- Node.js 14+ и npm
- git (опционально)

Установка
1. Клонируйте репозиторий или скачайте проект
   git clone <repo-url>
   cd mini-site-boots

2. Установите зависимости
   npm install

Локальный запуск
- Для продакшен-подобного запуска (поднимает сервер, раздаёт папку public):
  npm start
  Затем откройте http://localhost:3000

- Для разработки с авто-перезапуском (если установлен nodemon глобально или как devDependency):
  npm run dev

Положите файлы сайта (index.html, css, js, изображения) в папку public. Сервер автоматически раздаёт их.

Переменные окружения
- PORT — порт, на котором запускается сервер (по умолчанию 3000)

Деплой (несколько вариантов)

1) GitHub Pages (статический сайт)
- Если вы хотите развернуть только статическую версию (без Node.js), используйте ветку gh-pages или GitHub Pages через папку /docs.
- вариант A — ветка gh-pages
  - Соберите/подготовьте статические файлы в папке public
  - Используйте инструмент gh-pages для пуша в ветку gh-pages или настройте workflow GitHub Actions для публикации

- вариант B — папка docs
  - Скопируйте содержимое public в папку docs
  - В настройках репозитория GitHub включите Pages и укажите папку docs

2) Netlify / Vercel (статический сайт)
- Netlify
  - Перетащите папку public в Netlify для деплоя или подключите репозиторий и укажите папку сборки как public
- Vercel
  - Подключите репозиторий и укажите команду сборки (если нужна) и директорию вывода — public

3) Heroku (Node.js приложение)
- Подготовьте Procfile (опционально):
  web: node src/index.js
- Убедитесь, что package.json содержит start-скрипт
- Деплой через git push heroku main

4) Docker
- Пример Dockerfile (не включён в проект по умолчанию):
  FROM node:16-alpine
  WORKDIR /app
  COPY package*.json ./
  RUN npm ci --only=production
  COPY . .
  EXPOSE 3000
  CMD ["node","src/index.js"]
- Соберите и запустите:
  docker build -t mini-site-boots .
  docker run -p 3000:3000 mini-site-boots

Советы и отладка
- 404 или пустая страница: проверьте, что index.html лежит в public/index.html
- Порт недоступен: убедитесь, что переменная PORT не занята другим процессом
