# Минимальный проект

Краткое описание

Это минимальная заготовка Node.js-приложения. В этом README описаны шаги для локального запуска и запуска в контейнере Docker.

Предпосылки

- Node.js 14+ / 16+
- npm или yarn
- Docker (для контейнерного запуска)

Локальный запуск

1. Установите зависимости:

bash
npm install


2. Запустите приложение в режиме разработки:

bash
npm start


По умолчанию приложение слушает порт, указанный в переменной окружения PORT, или 3000.

Примеры:

bash
# запустить на порту 3000
PORT=3000 npm start


Запуск в Docker

Сборка образа:

bash
docker build -t minimal-node-app .


Запуск контейнера (проброс порта 3000):

bash
docker run --rm -p 3000:3000 --name minimal-app minimal-node-app


Перед использованием контейнера можно задать переменные окружения:

bash
docker run --rm -p 3000:3000 -e PORT=3000 minimal-node-app


Если у вас есть docker-compose.yml, стандартная команда:

bash
docker-compose up --build


Советы по разработке

- Для отладки полезно использовать nodemon (можно добавить в devDependencies).
- Проверяйте переменную окружения PORT перед запуском приложения.

Troubleshooting

- Если при сборке Docker контейнера приложение не стартует, проверьте логи контейнера:

bash
docker logs <container_id_or_name>


- Убедитесь, что порт, который вы пробрасываете, не занят локально.
