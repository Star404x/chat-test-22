# node-chat

Простой real-time чат на Node.js с использованием Socket.IO.

Требования
- Node.js 14+

Установка
1. Склонируйте репозиторий
2. Установите зависимости:

  npm install

Запуск
- Запустить в продакшене:

  npm run start

  (по умолчанию сервер ожидает файл server.js и порт, установленный в вашем server.js через process.env.PORT или 3000)

- Запустить в режиме разработки (авторелоад при изменении файлов):

  npm run dev

Тестирование (локально/на сервере)
- Запустите сервер (локально или на удалённой машине)
- Выполните smoke-тест клиента, который подключается к серверу, отправляет тестовое сообщение и ожидает его получения:

  npm run test

По умолчанию smoke-тест подключается к http://localhost:3000. Чтобы протестировать удалённый сервер, задайте переменную окружения SERVER_URL, например:

  SERVER_URL="http://example.com:3000" npm run test

Пример для деплоя на сервер
- Установите Node.js и зависимости
- Установите переменную окружения PORT (если нужно)
- Запустите npm run start или настройте systemd/process manager для автозапуска

Примеры поведения
- При успешном подключении и получении эхо/рассылки тестового сообщения smoke-тест завершится с кодом 0 и выведет "Smoke test passed".
- В противном случае тест упадёт с ненулевым кодом и сообщением об ошибке.

Дальше
- Проверьте, что server.js обрабатывает событие "chat message" и шлёт сообщения всем клиентам.
