# Mini Shoes Site

Кратко:
Мини-сайт для демонстрации и продажи обуви. В проекте использованы инструменты для локальной разработки (Vite), тестирования (Jest) и инструкции для оптимизации и деплоя на Vercel/Netlify.

Требования:
- Node.js 16+ и npm/yarn

Быстрый старт (локально):
1. Установите зависимости:
   npm install

2. Запустите режим разработки (локальный сервер с HMR):
   npm run dev

3. Соберите оптимизированную версию для продакшена:
   npm run build

4. Просмотреть собранный сайт локально:
   npm run preview

Тестирование:
- Запуск unit-тестов и отчёта покрытия:
  npm run test

Оптимизация и проверка производительности:
- Используйте Lighthouse (Chrome DevTools) для анализа производительности и доступности.
- Оптимизация изображений: конвертируйте большие изображения в WebP/AVIF, используйте srcset и lazy-loading.
- Включите компрессию на сервере (gzip / brotli).
- Настройте кеширование и CDN для статических ресурсов.
- Минимизируйте и делайте code-splitting, динамические импорты для больших библиотек.

Деплой на Vercel:
1. Зарегистрируйтесь/войдите на Vercel и подключите репозиторий (GitHub/GitLab/Bitbucket).
2. Настройте проект: Build Command: npm run build
   Output Directory: dist
3. Переменные окружения: если у вас есть API_KEYS или другие секреты, добавьте в Settings -> Environment Variables.
4. При пуше в основную ветку Vercel автоматически запустит сборку и задеплоит сайт.

Деплой на Netlify:
1. Зарегистрируйтесь/войдите на Netlify и подключите репозиторий.
2. В настройках сайта укажите Build Command: npm run build
   Publish directory: dist
3. Добавьте environment variables в Site settings -> Build & deploy -> Environment.
4. Netlify будет автоматически билдить и деплоить при каждом пуше.

CI / CD (генерал рекоммендация):
- В уже настроенной CI (GitHub Actions) добавьте шаги для npm ci, npm run test и npm run build, и опцию деплоя в Vercel/Netlify (если нужно).

Что делать дальше:
- Прогнать npm run test и исправить возможные ошибки.
- Прогнать Lighthouse и применить рекомендации по изображениям и кэшированию.
- Настроить автоматический деплой в Vercel/Netlify через репозиторий.
