# Chat Test 40

Краткое руководство по запуску, тестированию и подготовке ветки dev/auto.

Запуск приложения

1. Установите зависимости:

   npm install

2. Запустите сервер разработки:

   npm start

(Если ваш package.json использует другую команду — проверьте скрипты в package.json.)

Тесты

Проект содержит базовые тесты в папке tests. Для запуска тестов используйте:

   npm test

Тесты реализованы с использованием Jest (файлы с суффиксом .test.js). В тестах проверяются утилиты в src/utils.js.

Подготовка ветки dev/auto

Для автоматизации создания и пуша ветки dev/auto добавлен скрипт:

   scripts/create-dev-auto.sh

Запустите скрипт:

   sh scripts/create-dev-auto.sh

Скрипт:
- получает данные с origin
- создаёт локальную ветку dev/auto (или переключается на существующую)
- пушит ветку в origin и настраивает upstream

Альтернативно можно выполнить вручную:

   git fetch origin
   git checkout -b dev/auto
   git push -u origin dev/auto
